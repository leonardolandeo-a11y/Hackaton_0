# Manifiesto del ARCHIVO 2031

Este documento describe qué es la terminal de recuperación y por qué existe.

## Propósito

Conservar la bitácora del proyecto en un formato estable, legible y mantenible.

## Principios

1. Todo hallazgo se documenta con el comando exacto que lo produjo.
2. Nada se borra: se archiva.
3. Si algo desaparece del árbol de trabajo, sigue existiendo en la historia.
